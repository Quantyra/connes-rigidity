> We construct two explicit countable discrete groups Γ₁ and Γ₂ that are both ICC and have Kazhdan's property (T). ## 2. Main theorem (Connes rigidity counterexample claim)

### Connes' rigidity conjecture (as stated in the paper)

Every countable ICC property (T) group Γ is W∗-superrigid: if Λ is a countable discrete group with L(Λ) ≅ L(Γ), then Λ ≅ Γ as groups.

(The paper also recalls Houdayer's weaker higher-rank lattice form; Theorem A targets the **original** conjecture, not the lattice form.)

### Theorem A (precise claim as stated)

There exist explicitly defined countable discrete groups Γ₁ and Γ₂ such that:

1. both Γ₁ and Γ₂ have Kazhdan's property (T);
2. both groups are ICC;
3. Γ₁ ≇ Γ₂;
4. there is a ∗-isomorphism L(Γ₁) ≅ L(Γ₂) between their group von Neumann algebras.

**Proof assembly (paper §7):** countable from (2.3); (T) by Prop. 4.8; ICC by Prop. 5.3; non-isomorphism by Prop. 6.5; L-isomorphism by Prop. 3.4.

## 3. Group constructions Γ₁, Γ₂

### Fixed algebraic data

- Field: `k = ℤ/2ℤ`.
- Ring: `R = k[t]`, `A = R³` (free R-module of rank 3; also viewed as k-vector space with basis `{tⁿ eⱼ : n ≥ 0, 1 ≤ j ≤ 3}`).
- Flip: `Flip: A ⊗ A → A ⊗ A`, `a ⊗ b ↦ b ⊗ a`.
- `C = (A ⊗ A)^Flip` (Flip-fixed subspace).
- Diagonal: `Δ: A → C`, `Δ(a) = a ⊗ a`.
- `SL₃(R)` acts diagonally on `A ⊗ A` and hence on `C`.

**Lemma 2.1 (claimed):** There is a surjective SL₃(R)-equivariant linear map `δ: C → A` with `δ(Δ(a)) = a` for all `a ∈ A`, and square tensors `Δ(A)` span `C`.  
Construction sketch: ordered basis B of A; basis of C = `{b⊗b} ∪ {b⊗b'+b'⊗b : b < b'}`; set `δ(b⊗b)=b`, `δ(b⊗b'+b'⊗b)=0`.

### Symplectic side

- `V = k⁴` with coordinates `v = (a₁,b₁,a₂,b₂)` and standard symplectic form  
  `ω(v,w) = a₁b₁' + b₁a₁' + a₂b₂' + b₂a₂'`.
- Ordered symplectic basis `e₁,f₁,e₂,f₂`; matrix `J` of ω as in paper.
- `Q = Sp(V,ω) = Sp₄(k)` (finite).
- Quadratic refinement: `r₀(v) = a₁b₁ + a₂b₂`.
- Left action on functions: `(q · f)(v) = f(q⁻¹ v)`.
- `ℓ_q := q · r₀ − r₀` for `q ∈ Q`.

**Lemma 2.2 (claimed):** Each `ℓ_q` is linear in `V*`, and `q ↦ ℓ_q` is a 1-cocycle: `ℓ_{pq} = p·ℓ_q + ℓ_p`.

### Kernel and acting group

- `D = (A ⊗ V*) ⊕ C` (elementary abelian 2-group / k-vector space).
- `H = SL₃(R) × Q`.
- H-action on `A ⊗ V*`: `(l,q)·(a ⊗ φ) = l a ⊗ (q · φ)`.

### Two actions θ₁, θ₂ on D

For `(l,q) ∈ H` and `(u,c) ∈ D`:

```
θ₁(l,q)(u,c) = ( (l,q)·u , l·c )
θ₂(l,q)(u,c) = ( (l,q)·u + l δ(c) ⊗ ℓ_q , l·c )
```

**Lemma 2.3 (claimed):** θ₁ and θ₂ are genuine H-actions on D (θ₂ uses δ-equivariance + cocycle identity for ℓ).

### Definition of the groups (eq. 2.3)

Let `D_i` denote D equipped with action θ_i. Define

```
Γ_i = D_i ⋊_{θ_i} ( SL₃(R) × Sp₄(k) ) ,   i = 1,2.
```

Both are countable discrete (Q finite; all constituents countable).

### Design contrast with OpenAI (paper narrative)

- **Zhou:** fix H and elementary abelian D; change only the two H-module structures θ_i; non-isomorphism via **semisimple vs nonsemisimple** Q-module structure on D.
- **OpenAI (as described by Zhou):** fix H; change discrete abelian kernels D_i (torsion / binary-carry); non-isomorphism via finite-order elements when H is torsion-free.

Common mechanism (paper): Fourier transform  
`L(D_i ⋊_{θ_i} H) ≅ L^∞(D̂_i) ⋊_{α_i} H`;  
if induced dual actions α_i are conjugate as nonsingular probability-space H-actions (not necessarily as compact-group automorphisms), the group vNa may coincide while groups differ.

## 6. L(Γ₁) ≅ L(Γ₂) argument outline

**Goal (Prop. 3.4):** ∗-isomorphism of group von Neumann algebras.

### Dual picture

- For countable discrete k-module M, identify M̂ ≅ Hom_k(M,k) (characters land in {±1}).
- Dual of A⊗V*: `Z = Hom_k(A,V)`.
- `Ĉ = Hom_k(C,k)`, `D̂ = Z × Ĉ`.
- Quadratic-type map `R: Z → Ĉ` by writing z(a)=(x₁(a),…,x₄(a)) and  
  `R(z) = x₁⊗x₂ + x₃⊗x₄` (restriction to C); on squares `R(z)(Δ(a)) = r₀(z(a))`.
- Inverse dual actions α_{i,h}(χ) = χ ∘ θ_i(h)⁻¹.

### Key dual formulas (claimed)

- For l ∈ SL₃(R): both α_i,(l,1) act as `(z,y) ↦ (z∘l⁻¹, y∘(l⁻¹⊗l⁻¹))`.
- For q ∈ Q:  
  `α_{1,(1,q)}(z,y) = (qz, y)`,  
  `α_{2,(1,q)}(z,y) = (qz, y + J_q(z))` with `J_q(z)(c) = ℓ_{q⁻¹}(z(δ(c)))`.
- **Lem. 3.1:** `J_q(z) = R(qz) − R(z)`.

### Fiber shear conjugacy

- `F: D̂ → D̂`, `F(z,y) = (z, y + R(z))` (eq. 3.6).  
  Since Ĉ is a ℤ/2-module, `F⁻¹ = F`.
- **Prop. 3.2:** F is a Haar-measure-preserving homeomorphism and  
  `F ∘ α_{1,h} ∘ F⁻¹ = α_{2,h}` for all h ∈ H  
  (check generators q ∈ Q via Lem. 3.1; l ∈ SL₃(R) via SL₃-equivariance (3.3) of R; Haar by fiberwise translation).
- **Rem. 3.3:** R is generally **quadratic**, not additive ⇒ F need **not** be a compact-group automorphism; only measure-space conjugacy is used.

### Fourier / crossed-product chain (Prop. 3.4)

```
L(Γ_i) ≅ L(D_i) ⋊ H ≅ L^∞(D̂_i, μ) ⋊_{α_i} H
```

H-equivariant measure-space isomorphism F induces  
`L^∞(D̂₁) ⋊ H ≅ L^∞(D̂₂) ⋊ H`, hence `L(Γ₁) ≅ L(Γ₂)`.
